# Política de Privacidad de Extensiones de Chrome

*Última actualización: Septiembre de 2026*

Esta política de privacidad se aplica a las siguientes extensiones de Chrome desarrolladas por nuestra cuenta:
* **Insta Unfollower Humanized**
* **Auto Skipper & Video Controller**

Todas nuestras extensiones respetan plenamente tu privacidad. Operan de manera estrictamente local en tu navegador y están diseñadas como herramientas de productividad y control de medios.

* **Recopilación de datos:** Ninguna de las extensiones recopila, almacena, transmite ni comparte ningún tipo de información personal, credenciales, contraseñas, historial de navegación ni datos de las cuentas de los usuarios.
* **Funcionamiento local:** Toda la automatización, la inyección de controles y la gestión de elementos del DOM ocurren directamente en la pestaña activa del navegador del usuario. Ningún dato es enviado a servidores externos.
* **Uso de permisos:** Los permisos de host o pestaña activa se utilizan únicamente para permitir el correcto funcionamiento de las herramientas en sus respectivos sitios y reproductores.

Si tienes dudas sobre esta política, puedes contactarnos a través de la tienda de aplicaciones.
