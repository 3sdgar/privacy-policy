# Política de Privacidad de Insta Unfollower Humanized

*Última actualización: Septiembre de 2026*

**Insta Unfollower Humanized** respeta tu privacidad. Esta extensión de Chrome opera de manera estrictamente local en tu navegador y está diseñada como una herramienta de productividad para la gestión de listas de usuarios.

* **Recopilación de datos:** La extensión **no** recopila, almacena, transmite ni comparte ningún tipo de información personal, credenciales, contraseñas ni datos de las cuentas de los usuarios.
* **Funcionamiento local:** Toda la automatización y la gestión de elementos del DOM ocurren directamente en tu pestaña activa del navegador. Ningún dato es enviado a servidores externos.

Si tienes dudas sobre esta política, puedes contactarnos a través de la tienda de aplicaciones.
